# 离线示例报表制作说明

使用本目录 sample-data.csv 中的虚构数据。在 Power BI Desktop 中使用“输入数据”粘贴内容，销售额、订单数设为数值，空单元格保留 null，然后加载。这样示例不会依赖本地 CSV 路径刷新。

导入 dist 中 2.3.0.0 的 pbiviz。

1. “全国概览”页：地图绑定省份、城市、销售额及订单数提示，旁边放原生矩阵作对照。广东应为480000/450，浙江为150000/150，北京为280000/210，总计910000/810。
2. “北京区县”页：筛选省份为北京市，绑定省份、城市、区县、销售额及订单数；北京区县地图已内置，东城为0，西城为无数据。用于离线三级展示。
3. “格式与交互”页：演示标签、颜色、图例、右键菜单及与其他图表联动，明确百分比等不能在多级地图中按和汇总。
4. “使用说明”页：说明数据限制、网络权限、支持邮箱、隐私政策及未认证状态。

保存后断网重开 PBIX，验证上述所有演示路径。不要在离线演示中使用广东、浙江城市到区县的在线地图下载路径。截图必须来自真实运行界面，按1366×768 PNG导出或裁切排版。

本文件是制作步骤，不是已完成的 PBIX，也不代表宿主验证通过。
