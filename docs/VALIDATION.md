# 本地验证记录

## 2.3.2.0 区县联动补齐

上一版 applyLeafRegionFilter 只处理1/2级，三级仍走行选择。此次补齐区县字段目标和省+市+区县过滤，重复点击区县恢复所属城市，直辖市恢复省份；向上返回时移除残留子级条件。

19项模拟宿主回归测试通过，包括黑龙江→哈尔滨→道里区→南岗区→再次点击恢复哈尔滨，以及北京→海淀→再次点击恢复北京。类型检查和lint通过；真实Power BI报表联动仍需实际验证。

## 2.3.1.0 交互回归修复

移除工具提示中的“汇总方式”。省份/城市叶子点击改为字段过滤，与2.2.8之后的下钻联动保持同一接口；显式管理再次点击取消，城市取消后先移除城市过滤，再恢复所属省份。区县及缺少字段元数据时保留原有单行selectionId选择方式，真正多行分组才提交数组。选择请求未完成时不把临时空选择误认为宿主清除。

新增完整点击路径测试：仅省份点击/重复点击/切换省份；黑龙江下钻/哈尔滨点击/切换大庆/再次点击恢复黑龙江；三级区县原始身份与恢复城市；字段元数据缺失回退；同名城市省份约束；提示框内容。合计17/17通过，类型检查和lint通过。

这些测试验证真实生产逻辑到模拟宿主接口的请求，不代表已经在用户的Power BI报表上验证其他视觉响应。安装包保持原GUID，版本提升至2.3.1.0。
