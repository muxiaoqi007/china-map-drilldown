# 发布检查清单

目标版本：2.3.0.0，免费普通 AppSource 上架；不申请认证徽章。

## 发布前阻塞项

- [ ] 地图数据的再分发授权、来源、版本与展示要求核实完毕。
- [ ] 示例 PBIX 实际制作并断网测试通过。
- [ ] 300×300 Logo、1366×768 商店截图准备完成。
- [ ] 隐私政策及支持页面已公开且链接可访问。
- [ ] Partner Center 发布者资料完成。
- [ ] Desktop / Service 真机验证全部通过。

## 回归场景

- [ ] 省份；省份+城市；省份+城市+区县三种字段配置。
- [ ] 指标及附加指标使用可加总数值；与原生矩阵的 SUM 汇总一致。
- [ ] BLANK、零、负数、全空、单值及异常值；不能把空值显示为零。
- [ ] 下钻后修改颜色、标签、图例和提示开关，层级保留且设置生效。
- [ ] 右键数据区域与空白区域，菜单出现；核验区域身份对应正确。
- [ ] 多行聚合区域打开基础菜单，不能把首行身份当作整省整市；单行叶子区域显示数据菜单。
- [ ] 原生 tooltip、叶子层报表页提示、钻取及取消选择恢复父级联动。
- [ ] 连续下钻/返回、外部筛选、删除字段、页面切换、保存重开。
- [ ] 多实例、缩放、最小尺寸、仪表板固定、只读/编辑视图。
- [ ] 外网被禁用、地图接口失败、慢请求、异步加载时删除视觉对象。
- [ ] 数据截断时显示提示，不展示部分数据汇总。

## 自动检查

`npm run typecheck`、`npm run lint`、`npm test`、`npm run package`、`npm run audit:security`。

单元测试和成功打包不能替代真实 Power BI 宿主测试。自动检查结果见当前交付说明。

## 后续认证工作

区县地图全量本地化、删除外部请求及 WebAccess、完整认证审计、建立 certification 分支。任意非加总 DAX 度量需要迁移 matrix mapping 并由宿主返回层级小计，不能用下级求和或简单平均代替。
