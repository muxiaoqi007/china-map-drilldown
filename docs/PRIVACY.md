# 隐私政策

产品：中国地图下钻 V2。发布者：木小桼。更新日期：2026-09-17。

本视觉对象在 Power BI 提供的运行环境中处理报表传入的地区名称、度量值及格式设置，用于绘制地图、显示提示框和执行报表内筛选。产品自身不包含账号注册、广告、使用遥测或向发布者上传报表数据的功能。

全国和省级地图随视觉对象打包。未内置的区县地图通过 HTTPS 从 `geo.datav.aliyun.com` 获取，必要时回退到 `geojson.cn`。请求路径包含行政区划代码，不主动发送销售额、附加度量或原始报表行。地图服务提供者可能获得常规网络请求信息，例如 IP 地址、请求时间、地区代码以及浏览器允许发送的请求头；其处理方式受各服务提供者的政策约束。

下载的地图缓存在当前视觉对象的内存中。产品不使用浏览器持久存储保存报表数据。Power BI 平台自身的数据处理、报表存储及用户选择行为适用 Microsoft 和报表所属组织的政策。

管理员可限制外部网络访问；此时依赖在线资源的区县地图可能无法加载，全国及已内置地图仍可使用。产品未获得 Power BI Certified 认证。
