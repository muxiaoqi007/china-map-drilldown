# ChinaMapDrilldown - 中国地图层级下钻 Power BI 自定义视觉

基于 ECharts 的 Power BI 自定义视觉对象，实现中国地图省→市→区三级 Choropleth 填充地图下钻。

## 功能特性

- 三级层级下钻：全国 → 省份 → 城市 → 区县
- 内部点击下钻（无需依赖 Power BI 内置下钻功能）
- 三级面包屑导航（全国 › 省份 › 城市），支持逐级回退
- 标签内容可选：区域名称 / 数值 / 名称+数值（格式面板控制）
- 自定义工具提示字段（悬停显示额外度量）
- 南海诸岛显示模式切换（完整显示 / 小图显示）
- 颜色渐变图例条（可自定义最小/最大值颜色及范围）
- 缩放和平移支持
- 地图 GeoJSON 数据本地打包，Power BI Service 离线可用
- SVG 渲染器，兼容 Power BI Service CSP 安全策略

## 技术栈

- Power BI Custom Visuals SDK (pbiviz v5.5.1, API v5.3.0)
- ECharts 6 (SVG renderer)
- TypeScript (target: ES6)
- 地图数据：阿里云 DataV.GeoAtlas（已打包本地，回退在线获取）

## 开发

```bash
# 安装依赖
npm install

# 开发模式（启动本地调试服务器）
npx pbiviz start

# 打包
npx pbiviz package
```

打包后的 `.pbiviz` 文件位于 `dist/` 目录，可导入 Power BI Desktop 使用。

## 数据角色

| 数据角色 | 类型 | 说明 | 最大数量 |
|---------|------|------|---------|
| 省份 (province) | Grouping | 省份/直辖市/自治区 | 1 |
| 城市 (city) | Grouping | 地级市（下钻第二级） | 1 |
| 区县 (district) | Grouping | 区/县（下钻第三级） | 1 |
| 数值 (measure) | Measure | 驱动地图颜色渐变 + 标签显示 | 1 |
| 工具提示 (tooltips) | Measure | 悬停时额外显示的度量字段 | 5 |

## 格式面板设置

| 卡片 | 设置项 |
|------|--------|
| 地图配色 | 最小值颜色、最大值颜色、背景色、边界颜色、最小/最大值范围 |
| 标签设置 | 显示标签、标签内容（名称/数值/名称+数值）、字号、字体颜色 |
| 提示框 | 显示提示框 |
| 地图配置 | 缩放平移、图例条、面包屑导航、南海诸岛显示方式 |

## 使用说明

1. 将省份、城市、区县字段拖入对应数据角色
2. 将度量值（如销售额）拖入「数值」角色
3. 可选：将额外度量（如订单数）拖入「工具提示」
4. 全国地图点击省份 → 下钻到城市；点击城市 → 下钻到区县
5. 面包屑导航支持逐级回退
6. 格式面板中「标签内容」控制地图上显示什么文字

## Power BI Service 部署注意

- 需在管理门户开启「允许使用未经认证的视觉对象」
- 地图数据已打包在视觉内部，无需额外网络权限
- 若需下钻到未打包的省份（当前已打包 10 省），视觉会尝试在线获取
